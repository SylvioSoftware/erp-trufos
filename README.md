# Trufos ERP

Sistema web para gestão operacional e assistência técnica especializada.

---

## 📋 Visão Geral

Plataforma desenvolvida para centralizar o controle de cadastros, parque de equipamentos e ordens de serviço técnicas, oferecendo uma interface responsiva para operação em escritório e em campo.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
- **Backend & Integrações:** APIs REST, Automação de Fluxos e Banco de Dados Relacional
